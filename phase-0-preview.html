The Structured Template Engine

Templates are never saved as flattened MP4s. They are procedural data recipes containing media slots, layout rules, typography styles, and auto-crop behaviors.

01

Template Recipe

Defines abstract slots (PRIMARY_VIDEO, LOGO_SLOT, HOOK_TITLE) with layout, crop, and font constraints.

02

User Ingestion

The user uploads a new raw video (e.g. Episode 42) and picks the "Viral Podcast Short" template.

03

Procedural Instantiation

The engine clones the recipe, generating fresh UUIDs and injecting the new media IDs into the slots.

04

Independent Project

A completely new, editable project timeline is created. The original template remains 100% untouched.

V1 MVP Scope Discipline

        
To launch a high-quality product, we prioritize the core template engine and exclude unnecessary distractions.

      


      

        
        

          

            
            Must Have in V1 (MVP Core)
          

          
    
            
  • 
              
              Structured Template Engine: Save projects as data recipes; apply new media to slots.
            
    • 
            
  • 
              
              Multi-Track Timeline: Trimming, splitting, snapping, and track layering.
            
    • 
            
  • 
              
              Visual Transforms: Position, scale, rotation, opacity, and 9:16 / 16:9 canvas aspect ratios.
            
    • 
            
  • 
              
              Text & Subtitle Styler: Animated text presets and word pop captions.
            
    • 
            
  • 
              
              Cloud Rendering: Remotion/FFmpeg background worker rendering 1080p MP4.
            
    • 
            
  • 
              
              Stripe Billing: Free vs. Pro tier with monthly render minute tracking.
            
    • 
          

        


        
        

          

            
            Intentionally Excluded From V1
          

          
    
            
  • 
              ✕
              AI Video Generation / Generative Avatars: High external API costs, distracts from core editor.
            
    • 
            
  • 
              ✕
              Real-time Multiplayer Collaboration: Unnecessary synchronization complexity for V1.
            
    • 
            
  • 
              ✕
              4K Video Rendering: High server CPU consumption; 1080p is standard for shorts.
            
    • 
            
  • 
              ✕
              Mobile Native Apps: Desktop/laptop browser is the primary environment for serious editing.
            
    • 
            
  • 
              ✕
              Advanced Color Grading / LUT Shaders: Complex shader pipelines not needed for podcast shorts.
            
    • 
            
  • 
              ✕
              Large Stock Media Marketplace: Avoid expensive third-party licensing APIs.
